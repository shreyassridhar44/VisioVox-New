# 14 — Design System

---

## 1. Design direction

**Studio instrument, not consumer app.** The reference points are professional audio tools — dark
surfaces, precise typography, colour used as signal rather than decoration. The product deals in
waveforms, confidence and precision; the interface should look like it takes that seriously.

Three principles:

1. **Colour carries meaning.** Each speaker owns a colour and keeps it everywhere — waveform,
   card, caption, transcript, overlay ring. Colour is never decorative.
2. **Motion explains.** Every animation shows a relationship: separation, selection, time. Motion
   that doesn't explain something is removed.
3. **Uncertainty is visible.** Low confidence looks different from high confidence. The interface
   never presents a guess with the same authority as a certainty.

## 2. Colour

### Neutrals (dark-first)

```css
:root {
  --bg-base:      oklch(0.16 0.012 265);   /* page */
  --bg-surface:   oklch(0.21 0.014 265);   /* cards */
  --bg-elevated:  oklch(0.26 0.016 265);   /* popovers, menus */
  --bg-inset:     oklch(0.13 0.010 265);   /* wells, timeline bed */

  --border-subtle: oklch(0.30 0.014 265);
  --border-strong: oklch(0.40 0.018 265);

  --fg-primary:   oklch(0.97 0.005 265);
  --fg-secondary: oklch(0.76 0.012 265);
  --fg-muted:     oklch(0.58 0.014 265);
}
```

OKLCH throughout: perceptually uniform lightness means a palette generated by varying `L` produces
consistent contrast, which is what makes the WCAG checks pass by construction rather than by
iteration.

### Speaker colours

Chosen for maximum mutual distinguishability at equal lightness, and verified against the three
common colour-vision deficiencies.

```css
:root {
  --spk-1: oklch(0.72 0.17 235);   /* azure   */
  --spk-2: oklch(0.74 0.17 145);   /* jade    */
  --spk-3: oklch(0.76 0.16  75);   /* amber   */
  --spk-4: oklch(0.70 0.18 330);   /* magenta */
  --spk-mixed: oklch(0.62 0.02 265); /* neutral grey — the mixed track */
}
```

Equal `L` (~0.72) means no speaker reads as more important than another. The mixed track is
deliberately desaturated so isolated tracks feel like the active, "processed" state.

**Deuteranopia check:** azure/jade/amber remain separable; magenta/azure converge somewhat, which is
acceptable because it only occurs at 4 speakers and colour is never the sole identifier
(NFR-A11Y-06).

### Semantic

```css
--accent:        oklch(0.70 0.19 255);   /* primary action */
--success:       oklch(0.72 0.16 150);
--warning:       oklch(0.78 0.15  75);   /* low confidence */
--danger:        oklch(0.65 0.20  25);
--confidence-high:   var(--success);
--confidence-medium: var(--warning);
--confidence-low:    oklch(0.60 0.16  40);
--contested:         oklch(0.68 0.14 300);
```

### Light theme
Same tokens, inverted lightness. Speaker hues are preserved with `L` dropped to ~0.52 so they hold
contrast on white. Dark is the default; light is fully supported.

### Contrast enforcement
A CI script parses the token file, computes APCA/WCAG contrast for every defined foreground/background
pairing, and fails the build below threshold. Contrast is a test, not a review comment.

## 3. Typography

```css
--font-sans: "Inter Variable", system-ui, sans-serif;
--font-mono: "JetBrains Mono Variable", ui-monospace, monospace;
--font-display: "Instrument Serif", Georgia, serif;   /* landing headlines only */
```

| Token | Size / line-height | Use |
|---|---|---|
| `display-xl` | 4.5rem / 1.05, -0.03em | Hero |
| `display-l` | 3rem / 1.1 | Section heads |
| `heading-l/m/s` | 1.875 / 1.5 / 1.25rem | Page and card heads |
| `body-l/m/s` | 1.125 / 1 / 0.875rem | Content |
| `caption` | 1.5rem / 1.4, 500 | ⭐ Video captions — larger than body, deliberately |
| `mono-m/s` | 0.875 / 0.75rem | Timecodes, metrics, IDs |

Timecodes always use **tabular figures** (`font-variant-numeric: tabular-nums`) so digits don't
jitter as the playhead advances. Small detail, immediately noticeable when missing.

## 4. Spacing, radius, elevation

4 px base scale: `0.5 1 1.5 2 3 4 6 8 12 16 24` → `2px … 96px`.

```css
--radius-sm: 6px;  --radius-md: 10px;  --radius-lg: 16px;  --radius-full: 9999px;

--shadow-sm: 0 1px 2px oklch(0 0 0 / 0.3);
--shadow-md: 0 4px 12px oklch(0 0 0 / 0.35);
--shadow-lg: 0 12px 32px oklch(0 0 0 / 0.4);
--glow-speaker: 0 0 0 2px var(--speaker-color), 0 0 24px -4px var(--speaker-color);
```

`--glow-speaker` is the selection affordance for speaker cards — a ring plus a soft outer glow in
that speaker's colour, which reads clearly against a dark surface without adding a heavy border.

## 5. Motion

```css
--dur-instant: 80ms;    /* ⭐ matches the audio crossfade exactly */
--dur-fast:   160ms;
--dur-normal: 260ms;
--dur-slow:   420ms;

--ease-out:   cubic-bezier(0.16, 1, 0.3, 1);
--ease-inout: cubic-bezier(0.65, 0, 0.35, 1);
--ease-spring: linear(0, 0.4 12%, 0.85 24%, 1.05 38%, 0.99 60%, 1);
```

**`--dur-instant` equals the 80 ms audio crossfade in
[`12-media-pipeline-and-sync.md`](./12-media-pipeline-and-sync.md) §3.3.** The visual selection
transition and the audible transition are the same length, so the switch feels like one event
rather than two. This is the kind of detail that makes an interface feel solid without the user
being able to say why.

| Interaction | Motion |
|---|---|
| Speaker switch | Card fill + glow, 80 ms, `ease-out` |
| Caption change | 120 ms fade, no slide (slide impairs readability) |
| Active-speaker ring | 2 s breathing pulse, `ease-inout` |
| Timeline scrub | No transition — must track the pointer exactly |
| Page transition | 200 ms fade |
| Hero ribbons | Scroll-linked, not time-based |

**Under `prefers-reduced-motion`:** all durations → 0 except opacity fades, which are capped at
100 ms. 3D never initialises. Functionality is unchanged (NFR-A11Y-04, FR-SITE-06).

## 6. Signature components

### SpeakerCard
```
┌──────────────────────────────┐
│  ╭────╮                      │  ← thumbnail, or monogram if audio-only
│  │ 👤 │  Speaker 1        ●  │  ← ● = speaking-now indicator
│  ╰────╯  41% · ▓▓▓▓░░░░░░    │  ← speaking-time bar in the speaker colour
│                              │
│  ⚠ Audio-only                │  ← only when relevant
└──────────────────────────────┘
   selected → --glow-speaker + filled surface
```

### CaptionOverlay
```
┌────────────────────────────────────────────┐
│   the quarterly numbers came in higher     │  ← current word emphasised
│   ▔▔▔▔▔▔                                   │
│   ┃ Speaker 1                              │  ← 3px left bar in speaker colour
└────────────────────────────────────────────┘

low confidence → amber dotted underline + ⓘ
contested      → violet underline + "also attributed to Speaker 2"
```

### MultiLaneTimeline
```
 spk 1  ▁▂▅█▇▃▁░░░░░▂▅█▆▂▁░░░░▃▆█▇▄▁
 spk 2  ░░░░▁▃▆█▇▄▂░░░░░▂▅█▆▃░░░░░░░
 spk 3  ░░░░░░░░░░▂▄▇█▅▂░░░░░░░▁▄▇█▅
        ╎         ╎▓▓▓▓╎              ← ▓ = overlap region (hatched)
        ╎         ╎    ╎      ▲       ← playhead
```

This component does something no competing product offers: it makes the *structure* of the
conversation visible — who talks when, where they collide. It is both a navigation aid and the
clearest possible explanation of what the product did.

### ConfidenceIndicator
Dot + optional label. Green ≥ 0.7, amber 0.4–0.7, orange < 0.4. Tooltip always explains in plain
language what the number means for the listener — never a bare percentage.

## 7. Iconography

Lucide, 1.5 px stroke, 20 px default. Custom icons only for domain concepts with no standard glyph:
`waveform-split`, `speaker-isolate`, `overlap`, `confidence`. Drawn on the same grid and stroke
weight so they sit correctly alongside Lucide.

## 8. Voice and tone

| Situation | Do | Don't |
|---|---|---|
| Processing | "Isolating voices — about 3 minutes left" | "Executing stage S5_extract" |
| No face found | "No face found for Speaker 2 — isolating by voice alone." | "ASD binding failed" |
| Low confidence | "Speakers overlap heavily here, so this may be less accurate." | "Confidence: 0.38" |
| Error | "That file's audio couldn't be read. Try re-exporting it as MP4." | "MediaDecodeError: EBML header" |
| Limits | "Works best with 2–3 speakers. With 4, quality drops noticeably." | Silence |

The last row is the tone rule that matters: **state limitations before the user discovers them.**
It is the interface expression of Charter principle 7.1, and it is what makes the confidence
indicators trustworthy rather than decorative.

## 9. Implementation

- Tokens in `packages/ui/tokens.css` as CSS custom properties
- Tailwind v4 consumes them via `@theme`
- **Three.js reads the same tokens** — parse computed styles at init so 3D speaker colours match the
  DOM exactly, in both themes. A hardcoded hex in a shader that drifts from the token is a
  classic and very visible bug.
- Components in `packages/ui`, documented in Storybook
- Every component ships: default, hover, focus, active, disabled, loading, error, empty
- Visual regression via Playwright screenshots on the Storybook build
